HiDrop Loader Animation Demo

A benchmark and display showcase comparing background transparency approaches for the wave loading loop video file.

Background Color:
🔌 Method 1: CSS blend-mode
Zero Javascript calculations, pure hardware performance
⚡ Performance: Ultra Fast (0% CPU)
  • Smoothness: Perfect 60 FPS (Hardware Accelerated by GPU).
  • Weight: 0 KB JS overhead. Utilizes the native HTML5 player.
  • Alpha edges: Soft anti-aliasing details blend nicely with the background.
  • Ideal for: Light app backgrounds, cards, and clean white-themed sheets.
  • Drawback: Multiply effect will darken/reveal backgrounds on very dark pages.
🎨 Method 2: Canvas Chroma Key
Real-time pixel processing for complete transparency
⚙️ Performance: Lightweight (1-2% CPU)
  • Smoothness: High frame rate, controlled via canvas rendering loops.
  • Weight: Under 1KB of Javascript overhead to operate.
  • Alpha edges: Perfect transparency on **any** dark, colored, or gradient background.
  • Process: Scans each frame, identifies white/light gray pixels, and sets their alpha values to 0.
  • Ideal for: Dark Mode layouts, custom background gradients, and premium dialog overlay overlays.
